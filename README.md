# 台灣法律 RAG 問答系統 | Taiwan Law RAG Q&A System

A retrieval-augmented Q&A system for Taiwanese laws, built **from scratch in pure Python** — no external libraries, no API keys, runs 100% locally.

Ask a legal question in Chinese, and the system retrieves the most relevant articles from **1,300+ Taiwanese laws**.

```
$ python3 rag_taiwan_laws.py --query "機車違停罰款多少"

問題：機車違停罰款多少
============================================================
最相關的 5 篇法條：

[1] 《道路交通管理處罰條例》第56條
     相關度：31.42%
     內容：汽車駕駛人停車時，有下列情形之一者，處新臺幣六百元以上一千二百元以下罰鍰...
```

## How It Works

```
Question (Chinese text)
        │
        ▼
┌─────────────────┐
│  Tokenization    │  Split text into characters
└─────────────────┘
        │
        ▼
┌─────────────────┐
│  TF-IDF Vector   │  Convert text → numbers
│                  │  (importance of each character
│                  │   in one article vs. all articles)
└─────────────────┘
        │
        ▼
┌─────────────────┐
│ Cosine Similarity│  Compare question vector against
│                  │  all 1,300+ law article vectors
└─────────────────┘
        │
        ▼
   Top 5 most relevant articles
```

### Key design decisions

- **TF-IDF built from scratch** — implemented term frequency, inverse document frequency, and vectorization manually (with `math` and `collections` only) to understand the fundamentals rather than calling a library
- **Character-level tokenization** — Chinese has no spaces between words; character-level tokenization avoids needing a heavy word-segmentation dependency
- **Zero dependencies** — the entire system uses only the Python standard library, so anyone can run it with no setup
- **Pre-built index** — the TF-IDF index is computed once (`--train`) and cached with `pickle`, so queries are fast

## Usage

### 0. Download the law data (once)

```bash
python3 law_fetcher.py
```

Fetches laws from the Taiwan Ministry of Justice open-data API and saves them to `law_articles.json`. By default it pulls a focused set (labor law, consumer protection, company law, criminal law, civil law, copyright) — edit the `keywords` list to change the scope.

### 1. Build the index (once)

```bash
python3 rag_taiwan_laws.py --train
```

### 2. Ask a question

```bash
python3 rag_taiwan_laws.py --query "機車違停罰款多少"
```

### 3. Interactive mode

```bash
python3 rag_taiwan_laws.py
```
